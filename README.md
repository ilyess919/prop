# PROPATISS — thème Rose & Blanc

- `css/rose-theme.css` : tout le thème rose/blanc + animations (à charger après `propatiss.css`)
- `js/rose-animations.js` : animations (apparition au scroll, pétales, ondulation des boutons, inclinaison des cartes) — 3 Ko, sans librairie
- Pour changer la couleur principale : modifier `#ec4c8a` (rose) et `#d6336c` (rose foncé) dans `rose-theme.css`
- Les animations se coupent automatiquement pour les visiteurs qui ont activé « réduire les animations »
